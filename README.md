# Govee Shortcuts for Home Assistant

This custom component allows you to trigger Govee Tap-to-Run shortcuts and Dreamview snapshots as buttons in Home Assistant.

## Features
- Discovers Govee "BaseGroup" devices as buttons.
- Discovers "Snapshots" (Scenes/Dreamview) as buttons.
- Uses Govee OpenAPI.

## Installation
1. Go to HACS > Integrations.
2. Click the three dots in the top right and select "Custom repositories".
3. Add this URL and select "Integration" as the category.
4. Restart Home Assistant.
5. Go to Settings > Devices & Services > Add Integration and search for "Govee Shortcuts".

## Configuration
You will need your Govee API Key.
